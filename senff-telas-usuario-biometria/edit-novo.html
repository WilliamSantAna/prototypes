O Tipo de Usuário tem como objetivo auxiliar no gerenciamento dos usuários do sistema, mas não é utilizado para definir permissões de acesso.

Os Perfis de Acesso são responsáveis por determinar as permissões de acesso do usuário. Selecione os perfis que deseja associar ao usuário.

O grupo de permissão Acesso Básico oferece os acessos mínimos necessários para que o usuário consiga utilizar o sistema.

Atenção: O Acesso Básico é necessário para todos os usuários. Caso o usuário não possua o Acesso Básico, ele não conseguirá acessar o sistema.
